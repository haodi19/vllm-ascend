# Ascend 950PR 单卡 MoE 卸载四组实验：5 / 128 token

2026年11月12日晚，新PR服务器单卡运行DeepSeek-V4-Flash，Prefill与Decode同服务执行。两种输出长度各运行以下四组：

- **早期回调**：`callback_legacy`，CPU回调交接，Python LRC，开启debug。
- **当前回调**：`callback`，CPU回调交接，C++ LRC，关闭debug。
- **MTE默认**：`mte_default`，共享内存轮询交接，C++ LRC，关闭debug；`all/locked/yield`。
- **MTE组合**：`mte_combined`，共享内存轮询交接，C++ LRC，关闭debug；`allocated/atomic/yield`，即缩小扫描范围＋原子预检查，保留yield。

四组使用普通加载流；MTE在消费者处严格等待预取完成，权重准备与提交仍由Python/Torch执行。
每组独立启动服务，预热5次，测20次无profiler请求，再单独采集1次profile。输入均为5个token；输出分别为5个token（ignore_eos=false）和128个token（ignore_eos=true）。
各长度内四组输出摘要与token用量一致。下表原始值与筛选值来自同一轮实验，后续仅离线复核trace，没有重跑模型。

## 4. MEMCPY加载流空泡

每格为**均值μs / 样本数**。选择Stream 56，将MEMCPY、Transpose及其他设备任务都计为占用，只统计**10≤空泡<5000μs**，不叠加IQR。
本节采用**排除与任意已确认空载回调有时间重叠的整段空泡**（exclude_touching_any_empty）。原始列保留上述时长范围内、尚未排除空载重叠的结果；排除时不截短空泡、不拼接新间隔。

以**回调窗口、排除空载重叠后**比较，组合版相对早期回调的均值从609.703降至321.670μs（token5，降低47.242%），从653.325降至330.519μs（token128，降低49.410%）。

token128原报告因停止采集等待超时漏报间隔，以上数据来自同次已保存trace的离线恢复；8份trace的Host标记完整性均通过。Host与设备间隔各只有1次采集，请求级收益仍以上面20次无采集结果为准。
